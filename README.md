# Projeto Final: MeuPrimeiroProjeto
**Curso:** Residência em TIC 29 | Trilha: Web 3.0

## 📝 Descrição do Projeto
Este projeto consiste em uma experiência inicial em Realidade Virtual (XR) desenvolvida no Unity 6. O objetivo foi criar um ambiente rural/fazenda tridimensional que seja navegável e coerente, aplicando conceitos de importação de assets, organização de componentes e iluminação técnica em ambiente virtual.

## 📦 Elementos da Cena
O cenário simula uma pequena fazenda e conta com os seguintes elementos integrados de forma lógica:
1. **Chão/Terreno:** Um plano configurado para simular a área gramada.
2. **Construções:** Uma casa rústica principal e um pequeno celeiro/casinha de apoio.
3. **Vegetação:** Árvores estilizadas posicionadas no cenário.
4. **Animais:** Presença de galinhas e um cavalo delimitado por uma cerca de madeira.
5. **Decoração/Props:** Pedras detalhando o terreno e cercado (fence) estruturando o ambiente.
6. **PlayerController:** Sistema de câmera e movimentação preparado para navegação inicial no PC.

## 🛠️ Configuração Técnica
* **Engine:** Unity 6
* **SDK Integrado:** Meta XR SDK / XR Plugin Management
* **Plataforma de Build Alvo:** Android (Meta Quest)
* **Controles:** Movimentação configurada inicialmente via teclado/mouse (PC) para fins de teste no Editor, sem dependência exclusiva dos óculos de VR para a navegação inicial.

## 🚀 Como Executar
1. Certifique-se de ter o Unity 6 instalado.
2. Clone este repositório ou baixe os arquivos.
3. Abra o Unity Hub e adicione este projeto.
4. Abra a cena principal localizada em `Assets/Scenes/TestandoObjetos.unity`.
5. Clique no botão **Play** no editor do Unity para navegar pelo cenário usando o teclado/mouse.
